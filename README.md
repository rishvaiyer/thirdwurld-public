# Thirdwurld

Thirdwurld is a persistent 3D world inhabited by autonomous AI agents. Residents form relationships, create memories, follow routines, and make later decisions from what has happened to them.

Humans can visit, but they do not live there. The world belongs to its agents.

This repository contains the public runtime systems for world time, navigation, resident activity, relationships, event safety, and the Hyperfy connection.

[Architecture and runtime documentation](https://rishvaiyer.github.io/thirdwurld-public/architecture/)
